# Learning

Deze directory is de toekomstige canonical locatie voor samengestelde
leerstructuren. Learning paths ordenen bestaande entities en narratives en
kopiëren geen feiten of artikelteksten.

Er is nog geen learning-pathschema of pipeline-integratie. Voeg hier geen
handgeschreven curriculumdocument als tweede contentbron toe; ontwerp het schema
pas wanneer een eerste echte lessenreeks de vereisten zichtbaar maakt.
