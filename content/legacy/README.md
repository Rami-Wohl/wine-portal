# Legacy curriculum import

This directory is the non-destructive staging area for the current curriculum material.

- Keep imported source material intact until its replacement has been reviewed.
- Treat imported files as migration input, not canonical platform data.
- Record migration state in `editorial/migration-status.md`.
- Do not silently rewrite, relocate, or delete source material during import.

Curriculum modules belong under `modules/`. Their existing internal organization should be preserved on import unless a separately reviewed migration step says otherwise.
